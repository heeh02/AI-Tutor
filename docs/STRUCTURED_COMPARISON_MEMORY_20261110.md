# 实验比较约束进入记忆与教学

2026-11-10：3D Demo 已更新。保存一条实验观察后，“为什么记住”可以展开原始 A/B 条件、结果、次数、未测项和待做计划。教学上下文使用同一组经过来源核验的结构化记录，避免摘要省略“另一组没测”后，教学模型误把单次观察当作比较结论。

这承接了上一轮未采用的 v5 提示词实验。后台记忆摘要仍为已验 v4；没有放宽来源类别、版本、提升资格或请求预算。结构化记录补足摘要的背景，不代表摘要已经没有语义错误。

## 实现与边界

- Store 按记忆的真实来源 ID 反查比较记录，重新核验学习者、命名空间、活动、会话、来源角色与版本。没有单凭内容中的 comparison_id 建立关系，也没有复制一份新的业务文本表。
- A/B 的 reported/not_tested、原始结果、次数、共同条件与计划原话一起保留。未知次数和未测试分开；接受计划不等于完成，模拟或报告也不升级为硬件核验。
- 上下文按比较组去重，只跟随已选择的活动关系。任务、尝试和记忆引用同一组，并保留各角色的来源证据；背景来源不会被偷偷加入观察记忆的主来源。
- 条件、计划和来源链接作为整组进入既有预算。可选记忆超限时整条省略，不截断限制；没有关联时不添加空字段或额外指导。18000 数据字符、21000 引号转义 UTF-16 和 Windows 调用预算保持。
- 更正或忘记任一关联来源会使旧比较背景不可用，词法与向量召回均排除相关旧记忆。主观察仍可查看原句、更正或忘记；界面明确显示背景失效。
- 页面缓存绑定学习者 epoch；即使观察记忆行完全不变，另一个窗口忘记其关联计划也会清除旧详情，并拒绝迟到响应。手机布局让详情使用整行宽度。

主要模块：`store/memory_comparison.rs`、`context_comparison.rs`、`comparison_memory.rs`。前台比较指导独立放在 `prompts/comparison_context.md`，仅有关联时附加；`prompts/tutor_core.md` 与后台 v4 摘要提示词未替换。

### 实际模型观察

在独立模拟目录中使用已冻结的中文纸桥、英文 LED 两例，只有 3 次调用，未录音、打开摄像头、驱动云台或运行本地语音推理。

中文 Kimi 产生 2 个候选。观察摘要保留了 15cm、3 枚硬币、只试一次和最大承重未知，但没有明确写出 B 未测及比较限制；仅这条观察被人工检查后保留。计划摘要把原句不明指代“它”解释成“支撑物”，**语义失败**，已选择本次不保留。原始计划仍作为可核验的比较背景展示，未把被拒摘要恢复成记忆。

中文 Flash 回答明确指出 B 未测，不能断言跨度更长导致承重下降，并保留最大承重、同纸张、折法、硬币位置及新跨度的不确定性。已投递引用包含完整比较的三种来源角色。英文 Flash 正确保留 330Ω 未测、无电流/亮度测量和电压/次数未定，没有把 A 的 3V、一次测试借给 B。

中文验证了已保存观察及其比较背景；英文档案没有慢记忆，验证的是当前快记录路径。两例都没有增加完成实验或掌握结论。语义复核由另一助手完成，参与过实现，**不是人类盲评**；来源投递记录也不是新增结构导致质量提升的受控因果证明。
