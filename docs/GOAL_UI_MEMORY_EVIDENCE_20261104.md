# P4：可检查的记忆来源说明

日期：2026-11-04。实现范围为 Rust/Yew 记忆列表和 CSS；后端读取接口由主任务接线。未操作生产数据、浏览器或设备。修改前备份：`runtime/goal-backups/20261104/ui_review/memory-evidence/`。

## 组件和读取合同

`rust/tutor-ui/src/memory_evidence.rs` 的 `MemoryEvidence` 为每条当前记忆提供“为什么记住”。未展开时不读取详情，展开时调用同源认证的 `GET /api/learners/{learner_id}/memories/{memory_id}/evidence`，接收 Store 原值 `{memory,sources,source_links,namespace,education_metadata}`。每组件至多一个请求在途，不轮询来源详情；收起后重新展开会重新读取。

组件绑定当前档案、空间、列表中的完整 memory 快照与本地请求代次。切档、条目变化、编辑/删除对话框或操作开始会清空详情并使旧回执失效。来自另一档案、旧内容、旧来源集合或另一空间的快照不展示；结果不能把已收起的说明重新打开。旧请求只释放自己的请求槽，再按需获取当前展开的条目。接口失败或快照不匹配显示可恢复提示，不展示内部错误文本。界面语言改变保留当前证据和原句。

`view.rs` 仅接线组件与当前可用状态，保留原有更正、保存、取消、删除确认流程。没有新增升格、确认掌握或自动投递按钮。列表来源徽标改为明确的“学习者自述 / 已确认输入 / 模拟记录”；“更正记录”不一概称为教师更正。

## 展示边界

- 原句仅取 `sources[].content` 中字符串形式的 `text/report/correction`，保留大小写、空格和换行；结构化设置或缺原句的历史来源明确说明无可展示原句，不序列化整段 JSON。
- 日期来自原事件 `created_at`，以 UTC 日期展示；教育类型和当时帮助程度使用 `education_metadata.kind/support_level` 的本地化标签。旧记录缺元数据时显示未记录，不按年龄、内容或模型评分补推测。
- 重要性的四个0–3分项表示对未来教学的保留价值，不合并为可信度分数或学习成绩。可信度说明依据来源类型；教师确认输入不自动证明实验完成或掌握，模拟记录不作为真实学习表现的证据。
- 计划明确保留为待做；任务中的回答不变成固定能力标签。记录数量、来源重复或高重要性不提升来源等级。
- `source_links`、内部 ID、lease、worker 信息和 internal prompt 不进入展示投影。新说明及记忆行有中英标签；原有下方“本轮快记忆与召回条目”等界面的全面双语仍属后续范围。

CSS 为来源原句、字段列表和窄屏换行提供布局，不改生成的前端打包产物。

## 回归与当前验证状态

新增6项 Rust 回归：

1. 跨档案、空间、修订、编辑/删除开始后的迟到回执不能展示。
2. 收起/重新打开不会接受旧请求；已展示证据收起后清空。
3. 服务端返回不同来源快照时显示不可用，而非旧详情。
4. 原句只取白名单并保持原文，日期不透出未知字符串。
5. 模拟、计划和未知帮助程度保持原语义。
6. 四组完整合成响应可生成中英文视图，原句可见而内部 ID/提示/lease 不进入渲染树。

`rust/tutor-ui/fixtures/memory-evidence-20261104.json` 包含四组作者编写的接口响应（自述计划、已确认更正、模拟观察、无元数据旧记录）及六组双语操作脚本，实际浏览器状态均为 **NOT_RUN**。纯逻辑回归不替代网络接口、浏览器可访问性或窄屏验收。
