# 明确保存讲解偏好

新版 Demo 的“学习记忆 → 希望小宇记住的讲解偏好”可以保存用户原话，供后续活动使用。保存会替换此前长期讲解偏好；只想在本次活动使用的要求仍可直接在聊天中提出，不自动转为长期偏好。保存后可查看原句、保留理由，更正或忘记。

本片完成的是明确选择的持续偏好入口，不是后台 LLM 教育候选的全面自动提升。报告、概念证据、计划等现有类别门禁继续保留。

## 数据与失效行为

独立 Store 模块把保存操作记录为 `learner_statement` 原文，标明显式保存和持续作用域。真实档案保持 `learner_report`，模拟档案保持 `simulated`；用户确认不增加事实可信等级。慢记忆复用既有来源链接、跨活动召回和更正/忘记路径。

首次保存提升学习者记忆版本，不推进会话 generation。回执仅保留身份、版本及请求摘要，不再存一份原文。同一次未知结果重试复用请求键，不创建重复来源。替换时撤销旧偏好来源和派生内容，并按来源清理相关快状态，保留不相关事实。旧模型结果、旧保存回执在替换、更正或忘记后不能恢复旧偏好。
