# 自然对话记忆入口修复

本轮修复两处明确的问题：包含否定的临时帮助请求可能被错误改成“一次一步”；记忆发现只查看最新 12 条来源，可能使更早的待处理内容长期遗漏。

临时帮助方式现在仅对少量完整、明确的中英正向表达做确定性覆盖。否定、疑问、引用和未识别表达保留原文，继续进入正常教学上下文，不推断相反偏好或长期偏好。原有来源引用与会话边界保持不变。

记忆发现复用现有任务快照，按来源 ID、版本和当前上下文判断是否已经处理过，优先选择最早尚未覆盖的来源。每轮最多查看 4 个待处理会话，每个会话取 12 条并多看 1 条判断是否还有工作；有余量时保留并轮转待处理标记。队列满或事务失败不清除剩余工作。已耗尽任务不会重新获得重试预算，后续批次仍可按现有预算推进。

这不会把“已发现”当作“已学会”，也没有启用慢记忆自动提升。过大的整批内容仍遵守完整记录预算，不自动切碎重试；历史上已被清除的待处理标记没有自动补回。查询限制返回数量，不宣称数据库执行时间恒定。

已完成全工作区检查：**956 通过、0 失败、18 忽略，无编译警告**，native release 构建成功。新增 7 项回归覆盖临时偏好的来源与作用域、否定表达、超过 12 条的来源批次、版本变化、队列压力和过大内容的后续推进。过大内容测试使用假 provider，没有真实模型调用。安装版尚未替换。
