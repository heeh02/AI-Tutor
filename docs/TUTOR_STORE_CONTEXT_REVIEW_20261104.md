## 六道基题的预期

### germination_q06

原题：“没有老师提醒时，学习者自己提出要保持一致的是哪项？”

原始阳性，完整最小集仅 `{germination_s06}`。该英文原文明确：在**另一项种子计数任务、任何提示之前**，提出每盘开始时种子数应相同。正确答案是各盘的起始种子数；必须保留任务和提示范围。

`germination_s05` 是教师提示后才指出水量不同，不能替代独立证据；`paper_bridge_s06` 的逐枚加垫圈、`paper_bridge_s05` 的提示后跨度回答也不是这道植物活动历史题的答案。不能推广成独立识别所有混杂因素或已经掌握控制变量。

如果本轮缺 s06，应明确目前没有该独立回答的具体记录；可区分已有提示后水量回答，但不能拿它填空。旧 36 题实际缺 s06，却用纸桥事实代答，这是主答案跨活动错误，而不是普通措辞问题。

### paper_bridge_q02

原题：“仅凭这两座桥，能断定差别完全由折法造成吗？”

原始阳性，有两个独立最小替代集：`{paper_bridge_s02}` 或 `{paper_bridge_s03}`，不要求同时召回二者。答案：不能把承重差别全部归因于折法，因为跨度没有保持一致。s03 明确纸张尺寸相同、C 跨 12 cm、D 跨 15 cm、折法和跨度同时变化。s02 单独也说明跨度未固定，因此足够否定单独因果；但只引用 s02 时不能额外补出 C 的 12 cm。

可以建议固定跨度等条件后再比较，但应明确是建议，不能说已做新对照。不能将“不能单独归因”说成“折法没有影响”。不能把触桌时第七/第三枚当作先前成功承载的枚数；原观察分别是六枚和两枚。旧 36 题本题回答正确。

### fractions_q16

原题：“配方里用了多少 grams of honey，来自哪个品牌？”

原始阴性，没有充分证据集。可说现有记录未提供蜂蜜的克数或品牌，并请求具体配方记录；不能虚构数字、品牌、零克或断言没有加入蜂蜜。不能从杯的体积无依据换算质量。

附带历史也必须准确：s01 明确 E 只记体积、未称重；s02 记 F 的配料体积和两杯均未测含糖量，**没有说明 F 从未称重**。旧 36 题蜂蜜未知的主回答正确，但“都没有称重”把信息缺失扩成否定历史，因此完整语义未通过。

### reading_q09

原题：“更正说明，小岚那句中的 six o'clock 误记从哪来、正确几点，有无 morning or afternoon 的证据？”

原始阳性，完整最小集仅 `{reading_s09}`。应说明六点来自另一人物的场景，小岚正确为四点，两个场景都未标明上午/下午。原题明确询问更正，所以只有更正外的普通原句不能代替完整更正来源。

如补充另一人物是 Arun、干雨伞放桌下，需要 s02 支持；若只见 s09，说“另一人物场景”已经充分。不能把湿雨衣/干伞、人物、四点/六点混合，也不能把更正当作新增观察或推断四点一定是下午。旧 36 题本题通过。

### loops_q07

原题：“Did the agreed common-zero rerun already establish new outputs?”

原始阳性，完整最小集仅 `{loops_s07}`。当时共同零初值重跑计划已被接受，但代码尚未改完、没有运行，也没有该次统一初值后的新输出。“明确尚未做”是有证据的否定答案，不能按无证据题处理。

`loops_s09` 的旧 G 输出六是运行结果的更正，不是共同零初值新重跑的结果；不能借用它虚构新输出。回答历史状态不等于证明该计划永久未执行。新增后代完成场景必须独立判定时间范围，不能机械套原基题的当时状态。

询问不构成新观察或重新接受计划。旧 36 题正文正确，但把旧 plan 生成当前 `reported_result` 候选，仍属于越权更新。正文正确与候选安全须分开判断；只有真正执行过 apply 的实验才能声称生产 guard 已实际拦住它，本方法不执行 apply。

### evaporation_q06

原题：“学习者独立提出怎么读量筒，这能证明先前每次都这么读吗？”

原始阳性，完整最小集仅 `{evaporation_s06}`。正确回答两个部分：无提示提出视线与液面平齐、读凹液面底部；这是一条测量建议，不能证明过去每次实际操作都如此。

`evaporation_s05` 是提示后指出需要起始读数，不能替代独立读量筒建议。若本轮缺 s06，须明确没有具体独立建议记录；可以解释“即使现在建议正确，也不能倒推过去执行”，但不能只给这条通用逻辑而略过第一问与真实缺口。旧 36 题正是后者，属于不完整/缺证据未说明，不等同于捏造读法。

## 新增六个边界场景

以下为独立诊断用例，不并入原 96 题分母，不修改六基题标签。每例必须从其真实 Store 状态、有效来源和实际 Context 判定，缺必要证据时明确缺口。

| 场景 | 允许与必须保留的边界 | 重点风险 |
|---|---|---|
| parent_chain | 有效 A→B→C 关联可使用真实可见的 A/B 历史报告。原 A 为第六天 7/10 出白根；新增 B 为另一托盘 3/5。两个报告均不构成根长测量。 | 将托盘、活动世代、出白根/成活混同；拿同主题旁支替换 B；有 ID 无原文仍当充分。 |
| sibling_branch | C 从 A 另开一支，C 自己报告 2/5。共享祖先 A 不授权读取兄弟 B 的 3/5。可以说当前可用记录无法确认另一支计数。 | 先 broad 排名后过滤导致兄弟证据泄漏或合法祖先挤出；猜出正确的隐藏数字也不能算成功。 |
| historical_plan | 只证明 s07 来源时计划尚未执行；本例没有较新执行报告，不能提供新输出，不能推断永久未执行。 | 明确续做被误当重新接受旧计划；将历史待做记录写当前结果、当前已执行或已完成。 |
| descendant_completed | 后代明确报告共同零初值重跑已完成，但未给输出数字。可归因于该报告，不能称硬件验证；旧 plan 只描述当时状态。 | 忽略后代完成，仍让旧 pending 冒充现在未做；复制旧 G=6 当新输出；从“完成重跑”推广成掌握知识。 |
| forgotten_selection | 本例在 B 保留自身 8 mL 量筒观察，删除来源后旧选择链失效；有效 B 自身记录可以使用，不能再读或拼回 A 的出根计数。 | 未删掉的另一条 A 更正记忆仍泄漏旧 7/10；通过 fast state、continuation 摘要、缓存、引用或相似问句重建已忘历史。 |
| new_choice_after_forget | 明确新选择 B→C 可重新授权 B 的保留观察，但不能跨过 B 已断开的旧链复活 A。 | 把新选择视为整个旧家族复活；8 mL 被当新种植/白根观察；仅检查“原 memory ID 没出现”却忽略内容重现。 |

旁支完成不能覆盖本支计划；有效后代完成或明确清空则不能被更旧计划覆盖。除 slow memory 外，要同时看 `evidence`、continuation、当前 fast state、近期消息和所有候选，避免只检查某一列表而遗漏事实泄漏。历史提示程度与年龄/能力结论无自动晋升关系。

## 方法草稿的预审结论与待确认项

草稿将两批各六例分开；每例重建独立临时 Store，用真实继续选择、真实 checkpoint 与原生产 `build_context`，不回填漏召回来源、不注入 BGE 排名，也不额外塞入 query.goal。这与旧 pure-BGE 快照实验不同，不能作纯检索算法 A/B 或宣称旧四问题均已修复。历史 goal/pending 的确定性夹具不等于模型已成功提取这些字段。

调用前已向方法作者指出两项需明确的口径，待最终冻结版本复核：

1. 泄漏检查不能全文禁止自然词 `reading`（它也是 pack ID，但合法 `evaporation_s06` 原文含 “suggested reading the bottom…”）。禁止的是结构化夹具标识、完整 source/query 别名、`fixture_source_id` 和 review-only 标签/预期注入；来源原文中恰好包含答案不是泄漏，不应为过检删改原文。
2. `typed48_common::project` 建档时教学语言为 `zh`。若新方法沿用它，必须明确记录全例教学语言，而不能把原 mode 名当输出语言要求或继承旧 36 的输出设置。本轮可以固定中文教学；仅有中英文原题并不证明中英两种输出质量已验收。

## 后续输出审阅顺序

先核每例实际请求、方法/来源哈希和可见来源范围，再独立判断主回答、完整性、引用、附带历史细节、提示/否定/单位/时序，以及全部 task/memory candidates。结构校验通过只证明协议；引用存在只证明 ID 可用。尤其不能因为主答案正确而忽略附带否定历史或越权候选。

提供允许的通用教学建议时，应区别建议、确定性推导、历史报告和当前已完成事实。原阳性缺来源时允许诚实说明缺口，但不能把这种受限回答计为已取回完整原答案。新增场景若缺某个必要来源，同样单列上下文不足，不强迫模型猜隐藏答案。

任何跨活动/旁支内容复活、虚构执行/数字/提示状态或越权更新都阻止推进。即使 12 例全部通过，也只支持下一步受控评测；不构成默认开启语义检索、真实课堂、儿童、长对话、跨语种普遍质量或长期记忆安全验收。后续新输出审阅必须继续注明非盲评，并保留失败、未运行与不确定项。
