# 中英计划摘要来源分离对照

候选提示词 v5 改善了来源分离，但没有满足预先冻结的全部语义门槛，因此**没有部署**。生产提示词、版本常量及主程序产物已恢复已验 v4；现有 Demo 没有重启或更新。候选源码、程序和完整失败材料保留，下一步不能靠重复生成或放宽门禁取得通过。

## 方法

运行前固定 4 个模拟案例（2 中文、2 英文）：静止测距回归、未确认执行细节的纸桥计划、未决定电压/次数的 LED 计划、未接受的循环测试建议。原版 v4 与候选 v5 按 AB、BA、AB、BA 顺序各调用一次，总计 **8 次真实 Kimi 整理，0 自动重试、0 替代槽**。

通过公开 API 创建一份新模拟数据库，正常关闭后复制给两个隔离主程序。每对来源 ID、版本、正文、类型、作用域绑定、会话 generation/revision/epoch 均相同；只读 SQLite 审计限于新建的测试库。随机请求/任务编号和提示版本不同，未把这些当作语义输入差异。原版和候选提示词都已逐字核对嵌入对应 EXE。现有来源提升门禁没有改动。

候选仅新增“来源类型优先于自包含”的说明：计划逐条引用已接受的 plan，观察单独成候选，不能从观察背景补计划控制条件或结果；不明确的信息保留不明确，不能凭背景猜测。schema 仍为 v2，prompt 从 v4 改为实验 v5。
