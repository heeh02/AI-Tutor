# ASCEND 首轮真实语料评测

第24检查点新增诊断工具，完成两轮预先声明的实际 Zipformer 服务调用。完整语料阶段失败，12段实时回放阶段完成；这两项结果分别保留，不能相互补齐。P0–P5 Goal 继续 ACTIVE，生产候选沿用第23检查点，安装版未替换。

## 输入与方法

固定 CAiRE/ASCEND revision `737e9800ae31be9932ba8464c80366559bd28424` 的 test，共1,315段：中文685、混语373、英文257。原始 WAV 已逐条验证为16kHz单声道PCM16LE；提取52,847,779样本、3,302.9861875秒，不重采样、裁切或修改增益。仅两个匿名说话人，历史作者标注年龄24/25岁，每龄一人，不能推断年龄效应或儿童表现。数据许可CC-BY-SA-4.0，原始归属与许可保留于资产清单。

1279条不含字面`[UNK]`的参考用于主要文本指标，覆盖率97.2624%；其余36条未知参考及全部识别结果保留。未运行和失败条目不会从分母删除；相应空假设距离只用于明确标注的管线诊断，不能宣称完整模型准确率。CER和项目MER按累计编辑数/累计参考单位计算；项目MER并非原论文的jieba/tokenizer评分复现。归一化在模型运行前固定，不做同义词、繁简或数字修正。

两阶段都使用生产Rust AsrClient、响应校验及独立OwnedAsrService，顺序发送原始PCM，每块20ms；完整语料不等待媒体时钟，12段子集等待每块末样本应当到达的时刻。每阶段仅一个全新CPU服务、2线程、greedy search、自动语言，无音频重试或服务重启。模型final固有600ms尾零用于右上下文，不是录音尾静音或600ms墙钟等待。

完整语料的362条终稿包含36条合法空文本。第363条（ordinal362、ID00362）在已确认112块后发生`chunk_response_failed`，该条未收到终稿；保留失败时的partial，计分不把partial当终稿。按预定规则中止，剩余952条明确标记未运行。1315条记录均在，评分结果标为`incomplete_selected_inference`。**本轮没有完整语料的模型准确率结论。**

该诊断把底层错误收束为阶段代码，未保存原始的有界错误类别，因此现有记录不能区分连接、HTTP状态、解析、实例或修订校验失败。失败条目约342ms，不符合其60秒外层超时；这仍不足以判定根因。不能根据随后小样本通过推断故障已修复，也不能凭事后TCP状态断言端口耗尽。下一步先补精确的失败类别/sequence，再单独声明诊断输入与预算；原失败不重写、不补算。

实时子集实际媒体时长63.620秒，全部12条终稿完成。EOF发起final至结果返回中位数23.606ms、样本最大26.029ms；首个非空partial距首次PCM请求中位数897.016ms、样本最大1686.937ms。3181个分块请求至已校验响应中位数1.389ms、最近秩样本P95为12.491ms；发送相对媒体末样本可用时刻的迟到中位数8.485ms、最大52.274ms。

这12条中11条清晰参考的CER为82/325=25.23%，项目MER为36/183=19.67%；另1条未知参考完整保留。子集预先按元数据选取、数量很小，不能代替完整语料质量或总体P95。首partial包含发音和模型积累上下文的时间，不等于字幕滞后；EOF也不是实际松开录音键。此次没有运行CaptureStream重采样/有界队列、麦克风、VAD、界面、TTS或相机。

两个服务实例不同，均有模型释放、launcher/interpreter退出及空Job回执，`cleanup_confirmed=true`、`forced=false`。安装exe和旧外部服务描述文件哈希不变；未连接旧18867服务。描述文件不变不等于检查过其存活状态。

## 验证与下一步

新增3项Rust离线测试与9项Python文本测试实际通过；实际诊断libtest及320项源文件归档。只新增测试入口和评测工具，未重建生产release，也未把上一检查点851项结果冒充本轮重新执行。审查发现并修复了停止前输出I/O、未发请求误计attempt、写入失败误补not_run三个边界；磁盘故障未做系统级注入。

同时对既有60条教学调用作离线延迟分析：全部首个message超过5秒，最小6.134秒。当前证据不支持引入复杂的协议压缩或跨请求常驻CLI来解决主要等待；原2.5/5秒参考目标仍未达。分析未新增模型调用。

优先补ASR失败可观测性，再定位故障并完成完整语料及Paraformer同输入对照。已有Paraformer历史ONNX可复用，但其660ms尾部/is_final处理与当前Zipformer不同，来源链及既有英文截断问题仍须明确，不调整默认模型。儿童/青少年语音、自然听感、真实声学起止、长停顿/AEC、更大记忆联合负载、语义记忆和跨代删除、跟踪遮挡、浏览器及安装回退继续待验；实体云台运动按用户暂缓安排。
