## 已实现

- `ActivitySummary`：活动阶段、模块名称/报告状态、目标/观察/待测空状态、活动结束提示均跟随界面语言。学习目标、观察、尝试、待测计划保持原文；即使它们刚好等于某个界面标签，也不送入翻译映射。
- `ModuleInventory`：模块确认、报告输入提示、来源选择和保存反馈独立成小组件。沿用原 App 动作与 ModuleDraft，报告-only 不改变模块、显式全取消才表示无模块等校验保持。
- `ConfirmForget`：单条记忆与整个档案的标题、确认按钮、范围和不可撤销说明分别提供中英。原记忆正文和匿名档案名保持原文；仍使用原确认/取消动作，没有新增删除入口或改变删除范围。
- `OperationNotice`：已知录音恢复提示和操作结果使用当前界面语言；其余服务错误保持原文，放在可展开详情中，配套本地化恢复提示。回复失败入口、取回问题、关键 aria-label 和隐私/清除入口一并补齐。没有自动翻译服务返回、姓名、报告或模型输出。
- `evidence_labels.rs`：活动来源徽标、模块来源选择、比较记录和记忆共用“学习者自述 / Learner report”“人工报告确认 / Human-confirmed report”“模拟记录 / Simulated record”。人工确认明确针对报告，不是硬件验证或已掌握证明。
- `MemoryEvidence`：接收显式 `reading_level`。plain 使用短来源说明；所有模式先保留来源、实际记录的保留理由和原句。分类、当时帮助程度与重要性分项可展开，technical 默认展开。摘要只取 1–3 的已记录因素，缺失不补推断；不把分项当成绩、计划当完成。没有新增年龄标签或根据外观决定模式。

没有引入通用翻译框架。新组件只负责各自实际界面，继续使用现有 `i18n::t` 与既有状态/动作。
