# P1：临时录音字幕与检查后发送

日期：2026-11-04。范围为 Rust/Yew 字幕展示，不修改音频服务或远程模型调用。初始版本备份在 `runtime/goal-backups/20261104/ui_review/partial-captions/`；本次轮询改动前备份在 `runtime/goal-backups/20261104/ui_review/caption-poll-100ms/`。

`LiveTranscript` 位于 `rust/tutor-ui/src/live_transcript.rs`，作为输入区内的独立组件，仅录音或最终转写期间工作。旧实现每次 `GET /api/audio/status` 完成后再等 200ms，实际采样间隔包含请求耗时。本次改为用单调时钟记录请求开始，成功后只补足 100ms 起点间隔；请求本身超过 100ms 时，完成后只排一次下一请求，不积攒补发额度。始终最多一个请求在途。错误回执后等待 500ms；该 GET 独立使用 1.5s 超时，其他 API 超时不变。

绑定改变时保留旧请求占用的单一槽，旧回执不能修改新录音。旧请求退场后立即获取当前绑定，不继承旧请求的正常间隔或错误退避；无活动录音时停止调度。当前录音首次获取仍在 Start 完整回执绑定后立即发出，不等待全页状态轮询。

主工作台仍按原 1Hz 轮询，不随字幕提速。后续已经接入的实验语音轮换通过 `on_status` 接收 endpoint/错误状态；普通字幕状态在 App 中返回不重绘，字幕组件也只在文本/显示状态实际变化时重绘。本次没有扩展回调身份或全页重绘优化。

读取合同为：顶层 `recording_generation`、`asr_streaming_state`、`asr_provider`、`asr_fallback_reason`；`asr_partial` 为 null 或 `{recording_generation,revision,text}`。请求绑定完整四字段票据 `session_id/session_generation/language/recording_generation`；返回状态须匹配其录音代次，字幕 revision 只能递增。明确 null 清除字幕，新的录音或无活动录音会清除全部临时状态。旧会话/语言/录音迟到回执只释放自己的请求槽，不能恢复字幕或释放后续请求槽。短暂读取失败保留同次录音的最后临时文本并明确标记状态不可用；不将其作为最终结果。

字幕始终标为“录音字幕（未发送）”，临时文字不进入输入框、学习记忆或教学发送接口。只有现有 record/stop 的最终结果进入 `RecordingDraft` 的终稿保护流程：开始时为空且期间未编辑才自动填入，否则保留为待明确采用的转写。默认仍由用户检查、编辑并主动发送。App 保留票据直到最终回执；Stop、隐藏页面、设置变化和切会话沿用已有失效逻辑。已有显式启用的实验语音轮换仍只消费受票据/终点/编辑状态保护的最终转写，本次不改变其发送许可。

界面区分实时识别、最终整理、结束后本地转写和状态暂不可用；实际 provider 与 fallback_reason 放在可展开的识别状态中，原始诊断不自动翻译。中英文界面标签已提供，但不将其描述为全界面双语完成。后端流式模型、音频队列与回退实现由另一子任务负责。

本次新增 3 项纯回归：100ms 起点节奏/单请求/旧重复回执不释放新槽、绑定更换后立即恢复且解绑停止、仅字幕 GET 使用短超时。保留原字幕 revision、跨会话/语言代次、回退和 finalizing 测试。根任务统一workspace731项通过（含UI122项）、0失败、6忽略，无警告；`wasm-cadence-first.log` 的新WASM构建19.35秒成功。`fixtures/live-caption-tasks-20261104.json` 的中英浏览器任务仍为 NOT_RUN。本片没有浏览器、麦克风或播放实测。

独立只读复核确认，整个UI仅LiveTranscript调用该GET；录音Stop的90秒和其他服务停止期限未变。实验语音轮换遇到字幕GET挂起，会在1.5秒超时后更早按原网络错误逻辑暂停；手动录音显示字幕不可用并退避再读。没有自动重发教学请求或改写终稿。

后端此前观测的首 partial 约 832ms 包含固定语料的起始静音，不能直接称为 UI 显示延迟。本次仅确定缩短客户端轮询策略的等待项；没有浏览器实测，不能宣称首字已快了某个毫秒数，更不能把 100ms 轮询间隔当成完整字幕端到端延迟。
