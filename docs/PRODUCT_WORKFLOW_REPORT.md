# 教学流程与 CLI 发布验收

日期：2026-11-01。按最新安排，优先完善教学系统；界面由使用者操作，助手通过 Rust CLI 与本地接口控制。本轮未继续物理云台标定。

## 已发布的改动

- 模块表单从当前会话回填。只补报告不会改变模块；明确取消全部勾选才提交空清单。保存失败保留草稿。
- 结束或新建活动时先保存未提交的观察，保存失败就停止后续操作。已结束活动不能被取消、录音或报告请求重新激活。
- 结束时按有效来源保存报告原文，长中文报告有界分段；重复结束不重复保存。不把建议当成已做实验，不把历史模块恢复成当前连接。
- 人工观察进入有界历史，空报告保留已有结果。界面展示可读的观察、帮助偏好、结束回顾和下次相关记忆。
- 教师更正与模型更正均使关联旧来源失效，保留无关当前事实；旧任务不能重新写回。当前已显示的更正回复保留并继续满足播报校验。
- 模型失败后可取回上次问题到编辑框，由使用者检查后发送。云台详细状态折叠，教学和语音可独立使用。
- 新增 `bin/tutorctl.exe`：状态、档案、活动、文字输入、记忆、摄像头、音频控制；云台只开放状态与停止。固定本机认证接口，严格参数、凭证脱敏、不自动确认显示、不自动重试。转写单独最多等待90秒。
- 启动器拒绝未知参数，修正Kimi核验提示，记录脱敏启动错误；更新支持暂存、备份、正常停止和替换失败恢复。

完整命令见 [CLI.md](CLI.md)。
